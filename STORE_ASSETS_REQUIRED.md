# RiftReign Store Assets

## Included in this project

- `STORE_ASSETS/riftreign_play_icon_512.png` — 512×512 store icon.
- `STORE_ASSETS/riftreign_feature_graphic_1024x500.png` — 1024×500 feature graphic.

These should still be visually checked in Play Console's preview before publishing.

## Genuine screenshots still required

Capture screenshots from the actual v11 app after it is running on your emulator or phone. Do not use fabricated gameplay screenshots.

Recommended 4–6 landscape screenshots:

1. **Main menu** — clear RiftReign branding.
2. **Active combat** — multiple enemies, projectiles and HUD visible.
3. **Boss battle** — boss health bar visible.
4. **Hangar** — aircraft/cosmetic selection.
5. **Upgrade selection** — three upgrade cards.
6. **Game over / career** — score and progression.

Tips:

- Hide Android Studio chrome; capture only the emulator/device screen.
- Avoid debug overlays, notifications and personal information.
- Use the same actual UI users will receive.
- Check text remains readable at Play thumbnail size.

## Optional

A short gameplay trailer can help conversion, but it is not required for the first release.
